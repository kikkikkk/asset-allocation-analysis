# 资产配置分析（云端部署版）

双资产（沪深300 + 中债7-10年国债指数·财富口径）三组合对比分析工具，部署在 Streamlit Community Cloud 上。打开网页即自动展示真实历史数据分析结果，无需手动上传数据。

## 组合说明

| 组合 | 权重 | 说明 |
|---|---|---|
| 组合A（基准） | 沪深300 40% / 债券 60% | 固定权重 |
| 组合B（自定义） | 滑块任意调节，债券 = 100% − 股票 | 步长 1%，即时更新结果 |
| 组合C（最小方差） | 自动求解 | 约束：权重和 = 1，不做空 |

输出：算术平均日收益率、几何平均日收益率、年化收益率（252 交易日）、年化波动率（样本标准差 × √252）、累计净值曲线（期初 = 1）、Excel 导出（对比统计 + 净值 + 日度收益 + 计算假设）。

## 数据来源与合规说明

应用支持三种数据来源（侧边栏切换）：

1. **公开真实数据（默认）**：每次会话实时获取、缓存 1 小时。
   - 沪深300：腾讯财经公开行情接口（000300.SH 日收盘点位）；
   - 中债-7-10年国债指数·财富指数（CBA06501）：中国债券信息网（yield.chinabond.com.cn，中债估值中心官方公开网站）。
   - 已抽样核验：与 iFinD 导出的同指数数据一致（中债官网数据与授权渠道数据完全一致；沪深300 日收益率平均差异约 0，个别交易日存在极小差异）。
2. **上传的真实数据**：须包含「时间」与「收盘价(元)」两列（iFinD 或其他渠道导出均可），其余列自动忽略；请只上传获准公开使用的文件。
3. **模拟演示数据**：程序随机生成（种子固定、可复现），界面明确标注非真实行情。

**合规要点**：iFinD 导出数据受授权协议限制、不得公开再分发，因此本仓库**不包含任何真实行情文件、iFinD 数据或 API 凭据**（`.gitignore` 已拦截全部 Excel/CSV）；公开渠道数据在用户会话中实时获取，不落盘、不入库。

## 计算假设

- 日度简单收益率 R = (今天价格 − 昨天价格) / 昨天价格；两资产按共同交易日取交集，不填充缺失日期。
- **每日收盘后按目标权重再平衡**（每日固定权重）：组合日收益 = Σ w_i × r_i。与"买入持有不调仓"结果不同。
- 年化按 252 个交易日；最小方差权重由年化协方差解析求解并截断至 [0, 1]。
- 债券口径为**财富指数**（含票息再投资）；到期收益率 YTM 是利率水平而非回报，上传 YTM 数据时界面会拦截。

## 本地运行

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 部署到 Streamlit Community Cloud

1. 把本文件夹内容推送到 GitHub 仓库（`.gitignore` 已排除数据与敏感文件）。
2. 打开 https://share.streamlit.io ，用 GitHub 账号登录。
3. 「New app」→ 选择该仓库与分支 → **Advanced settings 里把 Python 版本选为 3.12 或 3.13**（依赖中的 pandas 3.x 要求 Python ≥ 3.11）→ Main file path 填 `app.py` → Deploy。
4. 部署完成后即可获得公网链接，老师无需登录即可访问。

## 数据更新机制

- **行情数据自动更新**：公开渠道数据在每次用户会话中实时获取（缓存 1 小时），无需任何手动操作，收盘后打开页面即为最新数据。
- **代码更新**：`git push` 到仓库主分支后，Streamlit Cloud 会自动重新部署，约 1–2 分钟生效。
