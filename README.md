# 资产配置分析（云端部署版）

双资产（沪深300 + 中债7-10年国债指数）三组合对比分析工具，部署在 Streamlit Community Cloud 上。

## 组合说明

| 组合 | 权重 | 说明 |
|---|---|---|
| 组合A（基准） | 沪深300 40% / 债券 60% | 固定权重 |
| 组合B（自定义） | 滑块任意调节，债券 = 100% − 股票 | 步长 1%，即时更新结果 |
| 组合C（最小方差） | 自动求解 | 约束：权重和 = 1，不做空 |

输出：算术平均日收益率、几何平均日收益率、年化收益率（252 交易日）、年化波动率（样本标准差 × √252）、累计净值曲线（期初 = 1）、Excel 导出（对比统计 + 净值 + 日度收益 + 计算假设）。

## 数据说明

- **默认使用模拟演示数据**：程序随机生成（随机种子固定、可复现），界面明确标注，**不代表任何真实行情**。
- 老师可自行上传获准使用的 iFinD 导出文件（Excel/CSV），文件须包含 **「时间」** 与 **「收盘价(元)」** 两列；代码、简称、涨跌幅等列自动忽略。两个资产都上传后，全部结果自动用上传数据重算。
- 本仓库**不包含任何真实行情数据、API token 或密钥**（见 `.gitignore`）。

## 计算假设

- 日度简单收益率 R = (今天价格 − 昨天价格) / 昨天价格；两资产按共同交易日取交集，不填充缺失日期。
- **每日收盘后按目标权重再平衡**（每日固定权重）：组合日收益 = Σ w_i × r_i。与"买入持有不调仓"结果不同。
- 年化按 252 个交易日；最小方差权重由年化协方差解析求解并截断至 [0, 1]。

## 本地运行

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 部署到 Streamlit Community Cloud

1. 把本文件夹内容推送到 GitHub 仓库（`.gitignore` 已排除数据与敏感文件）。
2. 打开 https://share.streamlit.io ，用 GitHub 账号登录。
3. 「New app」→ 选择该仓库与分支 → **Advanced settings 里把 Python 版本选为 3.12 或 3.13**（依赖中的 pandas 3.x 要求 Python ≥ 3.11）→ Main file path 填 `app.py` → Deploy。
4. 部署完成后即可获得公网链接，老师无需登录即可访问。
